# your-ai 🤖

আপনার নিজের AI চ্যাট অ্যাপ — সম্পূর্ণ ফ্রি, কোনো সার্ভার ছাড়াই ব্রাউজারে চলে।
বাংলা ও ইংরেজি — দুই ভাষাতেই কথা বলতে পারে।

---

## 🚀 কিভাবে চালাবেন (৩টি ধাপ)

### ধাপ ১: ফ্রি API key নিন
1. যান → [console.mistral.ai/api-keys](https://console.mistral.ai/api-keys/)
2. ফ্রি একাউন্ট খুলুন (Google/Email দিয়ে)
3. **"Create new key"** বাটনে ক্লিক করে একটি key কপি করুন

### ধাপ ২: অ্যাপ খুলুন
- **GitHub Pages দিয়ে (সবচেয়ে সহজ):** নিচের "GitHub Pages-এ প্রকাশ" অংশ দেখুন
- **নিজের কম্পিউটারে:** এই রিপোজিটরি ডাউনলোড করে `index.html` ফাইলটি ব্রাউজারে খুলুন — ব্যস!

### ধাপ ৩: Key দিন এবং চ্যাট শুরু করুন
1. অ্যাপ খুললেই সেটিংস বক্স আসবে — সেখানে আপনার API key পেস্ট করুন
2. **"সংরক্ষণ করুন"** চাপুন
3. এখন যা খুশি লিখুন — AI উত্তর দেবে! 🎉

## 🌍 GitHub Pages-এ প্রকাশ করুন (ফ্রি হোস্টিং)

একবার সেট করলে সারাজীবনের জন্য আপনার নিজের লিংক পাবেন:

1. GitHub-এ এই রিপোজিটরি খুলুন
2. **Settings → Pages** এ যান
3. **Source:** `Deploy from a branch` → Branch: `main` → Folder: `/ (root)` → **Save**
4. ১-২ মিনিট পর আপনার অ্যাপ লাইভ হবে:
   `https://nepsyp.github.io/your-ai/`

এই লিংকটি ফোন/কম্পিউটার — যেকোনো জায়গা থেকে খুলতে পারবেন।
